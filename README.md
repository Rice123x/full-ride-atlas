# Full-Ride Atlas

A research platform for international students applying with A-levels and the SAT:
257 universities across 59 countries with honest funding tiers (guaranteed full ride /
full need-based aid / competitive full scholarship / tuition scholarship / tuition-free /
low tuition / partial), dedicated per-university profile pages (official links, application
info, aid stats, academics, essay prompts with in-browser drafting), smart filters,
side-by-side comparison, an application checklist dashboard, Common App activity &
honors builders, and CSV/print export.

**Stack:** one self-contained `index.html` — no build step, no dependencies.
Deploy anywhere static (Vercel, GitHub Pages, Netlify).

**Accuracy:** rankings/acceptance rates are approximate 2025–26 bands; deadlines are
typical cycles. Always verify on the official pages linked in each profile.
Compiled July 2026.
